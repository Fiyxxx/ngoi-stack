# Wording slop

Applies to UI text, error messages, docs, commit messages and PR text. Adapted from pstack's unslop (MIT).

## Words

- AI vocabulary: delve, crucial, pivotal, robust, seamless, leverage, utilize, enhance, foster, showcase, underscore, tapestry, landscape, testament, vibrant, intricate. Use the plain word.
- "Serves as", "stands as", "boasts", "features". Say "is" or "has".
- Abstract nouns pretending to be technical: paradigm, surface (as in "API surface"), substrate, vector (meaning "way"), north star, flywheel. Name the concrete thing.
- Filler: "in order to" becomes "to", "due to the fact that" becomes "because". Cut "it is important to note that".
- Hedging stacks ("could potentially possibly"). Say "may" once, or state the fact.
- Adverbs propping up weak verbs ("significantly improves"). Give the number or a stronger verb.

## Structure

- "Not just X, but Y." State the point.
- Groups of three forced for rhythm. Use the real number.
- Cycling synonyms for one thing. Pick a name and repeat it.
- Em dashes. Use a period or a comma.
- Colons used as mid-sentence connectors. A colon before a list is fine.
- Bold on every term, emoji in headings, Title Case Headings. Use sentence case.
- Bold label plus colon that restates the line ("**Speed:** Speed improved").

## Tone

- Chatbot phrases: "Great question", "Certainly!", "I hope this helps", "Let me know if".
- Sycophancy and hype. State the fact.
- Generic endings ("The future looks bright"). End on the last useful fact.
- UI copy that sounds like marketing: "Unlock", "Supercharge", "Effortlessly", "Oops!", exclamation marks.

## Plain speech

- Say what it does, not how it feels. "A column rename fails the build" beats "types that follow your schema".
- If a sentence could appear unchanged in another project's docs, it says nothing. Cut it.
- One idea per sentence. Split anything the reader has to parse twice.
- Active voice, with the actor named.
- Error messages say what happened and what to do next, in the user's words.
