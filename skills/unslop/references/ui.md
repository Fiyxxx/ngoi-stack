# UI slop

The repo's design system wins over this list.

- Coloured left-edge stripes on cards or banners. Accent bars on selected rows.
- Icons in tinted squares or circles. An icon in every pill, heading or menu item.
- ALL-CAPS labels. Badges inside buttons.
- Cards nested inside cards. Boxed grids for simple details. Quiet label and value pairs read better.
- Gradients, glows, heavy shadows and decorative emoji.
- Several surface shades for banners, hovers, selected states and pills. Use one neutral shade.
- Colour used for decoration. Colour only carries meaning (error, warning, success), and always comes with words.
- "·" as a separator between pieces of data.
- "None", "N/A" or "-" for empty fields. Hide the field.
- Native `<select>` or one-off styled controls where the app has its own component.
- Generic empty states and hero copy ("Welcome back!", "Get started", "Nothing here yet!").
- Layout shifts and re-renders where a state change should animate in place.
